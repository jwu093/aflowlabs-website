Getting started

How do I add books?

Open Bookshelf. In the More Library Actions menu (the three dots), choose Add Books to select supported files through Files.

For a folder, choose Library Sources from that menu, then the Add Library Folder button (folder with a plus). In Folder File Types, select the supported types you want scanned, tap Choose Folder and select the folder in Files. This guide focuses on EPUBs.

A folder source lets Aflow Read discover supported books within that location, including nested folders. Access, file availability and supported content still matter; not every file is guaranteed to import. Keep your original books and independent backups.

Bring folders together

Can I add a parent folder containing existing sources?

Yes. Add the parent through Library Sources → Add Library Folder. If it contains previously registered child sources and Aflow Read can qualify their coverage, you will see Consolidate Library Sources?

  1. Review the confirmation and choose Consolidate Sources, or Cancel to keep the existing setup.
  2. Watch the current stage: Preparing Source, Discovering Books, Reconciling Library and Saving Library.
  3. Wait for Sources Consolidated. The parent replaces the covered child-source registrations after successful reconciliation.

Consolidation reorganizes the app’s source registrations and file references. It does not move or delete your original EPUBs. It is designed to preserve existing logical books, progress, bookmarks and collections. If access or coverage cannot be verified, the original sources are retained.

Can I stop consolidation or tap Done?

Before saving begins, use Cancel Consolidation or tap Done to open Stop consolidating? Choose Keep Consolidating to continue or Stop Consolidation to request a stop.

Wait for Consolidation Stopped before treating the operation as cancelled. The original library and sources are retained when stopping completes before the commit boundary.

Once Saving Library begins, saving must finish. Done explains that saving is finishing; it cannot undo committed changes. Refresh and conflicting source actions are unavailable while consolidation is active.

If the source was saved but its display could not refresh, follow the message to reopen Library Sources. That display issue does not mean the saved change was rolled back.

Understand library counts

Why are there more linked EPUB files than books?

One logical book can have several linked EPUB file references. Bookshelf normally shows one entry for that book.

  • Linked EPUB files: references currently linked to library books in that source.
  • Books in this source: distinct logical books represented by those references.
  • Additional EPUB copies: linked references beyond one per logical book.

Open a source in Library Sources. When multiple-file relationships exist, turn on Show books with multiple files to inspect them. The label “copies” does not establish that the files have identical bytes. Do not delete or merge files just to make counts equal.

These counts describe EPUB records already known to the app. Unavailable files may remain linked, and a partial or failed refresh may not describe every file currently in the folder. Bookshelf search, filters, visibility and other sources can also affect a comparison.

Missing or unavailable books

How do I restore access to a source?
  1. Check in Files that the original folder or EPUB still exists. Make sure its provider is connected and the file can be opened or downloaded.
  2. Open Bookshelf → More Library Actions → Library Sources. Open the source and use Refresh, or press and hold its source row and choose Refresh Source.
  3. If access is needed, press and hold the source row and choose Restore Access to select the appropriate folder or file again. Retry Access rechecks existing permission. For an available source, the menu instead offers Choose Folder Again or Choose EPUB Again.

A moved, renamed, disconnected or inaccessible file is different from a book deliberately removed from the library. Refresh cannot recover a physically deleted file. Avoid deleting Aflow Read as a troubleshooting step: this may remove local reading information.

What if a book was deliberately removed?

Open the relevant source in Library Sources and check Removed from Library. When removed entries are present, Recovery Actions offers Select Removed Books or Restore All Removed. Restoring an entry still depends on access to its file.

Reading and navigation

How do I open a book and adjust the page?

Tap a book in Bookshelf to open it. While reading, show the reading controls and tap Aa (Reading appearance) to adjust text size, typeface, spacing and reading mode.

Single Page uses one column. Automatic and Facing Pages can use two when the available reading width and supported presentation allow it. A narrow view can use one column while retaining your saved preference.

How do I use bookmarks, Contents and Search?

Use Add bookmark in the reading controls to save the current location. If the location is still being confirmed, wait until the bookmark control is ready.

Open Reader navigator and choose Bookmarks to return to a saved place, or Contents to choose a section. In More reader actions (the three dots), choose Search in Book to search supported EPUB content.

After a supported jump, a Go back to… control appears near the reading progress. Use it to return to the previous passage.

How do I browse illustrations and return to reading?

Open More reader actions → Illustrations and select a supported image to visit its place in the EPUB. Use the resulting Go back to… control to return to your earlier passage.

Availability and exact targeting depend on the EPUB’s authorship. Some vector-only or unusual content may not offer a supported gallery target.

Reading state and files across devices

The initial Free release maintains reading progress and library information locally. You can select files and folders through supported Files providers, including iCloud Drive where available.

Putting an EPUB in iCloud Drive does not automatically synchronize Aflow Read’s bookmarks, collections or reading positions. Structured automatic cross-device library and reading-state synchronization is not part of the initial Free release.

Contact and troubleshooting

Email help@aflowlabs.com, or use Settings → Send Feedback. The email can be reviewed and edited before sending. Its prepared footer includes app version, device family and operating-system information; books and diagnostic files are not automatically attached.

Describe the issue, your device and iOS version, and the steps that led to it. We do not need your EPUBs, reading history, private library catalogue or diagnostic exports in the first message. Any further information should be shared voluntarily after discussing what is useful.
